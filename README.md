# سهم حسن قربان‌نژاد در گام ۳: EDA و آمار توصیفی

این بسته برای سهم من در پروژهٔ گروهی تشخیص ژانر موسیقی آماده شده است: بررسی توزیع داده‌ها و محاسبهٔ آمار توصیفیِ تعداد فایل‌ها در هر سبک، شامل میانگین و واریانس، همراه با نمودار و تفسیر.

تحلیل با metadata ثبت‌شده در مخزن پروژهٔ گروه انجام شده است. در نسخهٔ بررسی‌شده ۱۴ فایل در پنج سبک وجود دارد. فایل CSV در مخزن گروه مرجع نهایی است؛ قبل از تحویل باید اسکریپت را روی همان فایل اجرا و نتیجه را با نسخهٔ فعلی بررسی کنم.

## محتویات

- `src/descriptive_stats.py`: محاسبهٔ فراوانی، درصد، میانگین، میانه، واریانس نمونه و جامعه، انحراف معیار و ساخت نمودار.
- `notebooks/descriptive_statistics.ipynb`: اجرای مرحله‌به‌مرحلهٔ تحلیل در Jupyter.
- `reports/descriptive_statistics.md`: نتیجه، تفسیر، محاسبات و محدودیت‌ها.
- `reports/plots/`: خروجی نمونهٔ نمودار و جدول‌های آماری.
- `README_section_for_project.md`: متن پیشنهادی برای افزودن به README اصلی پروژهٔ گروه.

## اجرا در مخزن پروژه

این فایل‌ها را با حفظ ساختار پوشه به مخزن پروژه اضافه کن. سپس از ریشهٔ مخزن اجرا کن:

```bash
python -m pip install pandas matplotlib
python src/descriptive_stats.py --metadata data/processed/metadata.csv --output reports/plots
```

اسکریپت فقط از ستون‌های `genre` و متادیتای فایل استفاده می‌کند. چون CSV موجود ستون عددی ویژگی صوتی ندارد، این تحلیل میانگین و واریانس **تعداد فایل‌های هر سبک** را گزارش می‌کند، نه MFCC، طول صوت یا دیگر مشخصات موج.

## یادداشت برای مخزن شخصی

چون استاد خواسته هر عضو گام‌ها را به‌صورت فردی در مخزن شخصی خودش ثبت کند، این بسته را در مخزن شخصی خودم قرار می‌دهم و در README/گزارش مشخص می‌کنم این سهم من از کار گروهی است. آمار باید از دادهٔ موجود در مخزن گروه بازتولید شود؛ فایل‌های صوتی گروه را بدون مجوز در مخزن شخصی کپی نمی‌کنم.
