# سهم حسن قربان‌نژاد — آمار توصیفی و ارزیابی داده‌ها

## دامنه و دادهٔ بررسی‌شده

این گزارش از فایل `data/processed/metadata.csv` مخزن پروژهٔ Veiseh استفاده می‌کند. در نسخهٔ بررسی‌شده، فایل metadata شامل **۱۴ رکورد صوتی و ۵ برچسب سبک** است. تحلیل حاضر فقط آمار توصیفیِ تعداد فایل‌ها در هر سبک را محاسبه می‌کند؛ چون در metadata ستون‌های عددیِ ویژگی صوتی (مثل مدت‌زمان، نرخ نمونه‌برداری یا MFCC) وجود ندارد، میانگین و واریانسِ سیگنال صوتی ادعا یا حدس زده نشده است.

## فراوانی و سهم هر سبک

| سبک | تعداد فایل | درصد از کل |
|---|---:|---:|
| blues | 3 | 21.43٪ |
| classical | 2 | 14.29٪ |
| hiphop | 5 | 35.71٪ |
| jazz | 1 | 7.14٪ |
| rock | 3 | 21.43٪ |
| **مجموع** | **14** | **100٪** |

## میانگین و واریانس تعداد فایل در سبک‌ها

متغیر آماری در این قسمت «تعداد فایل‌های هر سبک» است؛ بنابراین پنج مقدارِ تحلیل‌شده برابر `[3, 2, 5, 1, 3]` هستند.

| آماره | مقدار | تعریف |
|---|---:|---|
| تعداد سبک‌ها | 5 | تعداد گروه‌ها |
| تعداد کل فایل‌ها | 14 | مجموع شمارش‌ها |
| میانگین فایل در هر سبک | 2.80 | مجموع شمارش‌ها تقسیم بر ۵ |
| میانه | 3 | میانهٔ شمارش‌های مرتب‌شدهٔ `[1,2,3,3,5]` |
| واریانس جامعه | 1.76 | `Σ(xᵢ − 2.8)² / 5`؛ کل سبک‌های حاضر در این metadata توصیف شده‌اند |
| واریانس نمونه | 2.20 | `Σ(xᵢ − 2.8)² / 4`؛ برآورد نمونه‌ای با ddof=1 |
| انحراف معیار جامعه | 1.33 | جذر واریانس جامعه |
| کمینه تا بیشینه | 1 تا 5 | Jazz کمترین و Hip-hop بیشترین نمونه را دارد |

در این گزارش، چون همهٔ پنج سبک موجود در فایل بررسی‌شده داخل محاسبه‌اند، برای توصیف همین فایل **واریانس جامعه (ddof=0)** مقدار اصلی است. واریانس نمونه نیز برای شفافیت نمایش داده شده است؛ این دو تعریف مخرج متفاوت دارند و نباید با هم اشتباه شوند.

## برداشت از نتیجه

- تعداد نمونه‌ها بین سبک‌ها برابر نیست: Hip-hop با ۵ فایل (۳۵٫۷٪) بیشترین و Jazz با ۱ فایل (۷٫۱٪) کمترین نمونه را دارد.
- میانگین ۲٫۸ فایل برای هر سبک و واریانس جامعهٔ ۱٫۷۶ نشان می‌دهد شمارش کلاس‌ها حول میانگین یکسان پخش نشده است. اختلاف بیشینه و کمینه ۴ فایل است.
- با فقط ۱۴ نمونه، این اعداد برای توصیف همین مجموعهٔ کوچک مفیدند، اما برای نتیجه‌گیری دربارهٔ توزیع عمومی سبک‌های موسیقی یا آموزش/ارزیابی قابل‌اعتماد مدل کافی نیستند. به‌ویژه یک نمونهٔ Jazz برای ارزیابی مدل کفایت ندارد.
- پیش از split آموزش/آزمون یا آموزش مدل، باید نمونه‌های بیشتری برای هر سبک گردآوری شود. تا آن زمان، توازن کلاس و محدودیت اندازهٔ داده باید صریحاً در گزارش ذکر شود.

## بازتولید تحلیل

از ریشهٔ مخزن اجرا کنید:

```bash
python -m pip install -r requirements.txt
python src/descriptive_stats.py --metadata data/processed/metadata.csv --output reports/plots
```

اسکریپت جدول شمارش و درصد را در `reports/plots/genre_descriptive_stats.csv`، آمار خلاصه را در `reports/plots/summary_statistics.csv` و نمودار را در `reports/plots/genre_counts.png` می‌سازد. عددهای این گزارش از شمارش‌های ثبت‌شده در README و metadata نسخهٔ مخزن هنگام بررسی محاسبه شده‌اند؛ اجرای اسکریپت روی CSV به‌روز، مرجع نهایی اعداد خواهد بود.
