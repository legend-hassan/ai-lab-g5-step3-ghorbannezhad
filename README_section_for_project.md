## سهم حسن قربان‌نژاد: آمار توصیفی و ارزیابی اولیهٔ داده‌ها

در این بخش، تعداد فایل‌های ثبت‌شده در هر ژانر محاسبه و توزیع نمونه‌ها بررسی شد. در نسخهٔ بررسی‌شده از `data/processed/metadata.csv`، ۱۴ فایل در پنج ژانر وجود دارد:

| ژانر | تعداد فایل | درصد |
|---|---:|---:|
| Blues | 3 | 21.43٪ |
| Classical | 2 | 14.29٪ |
| Hip-hop | 5 | 35.71٪ |
| Jazz | 1 | 7.14٪ |
| Rock | 3 | 21.43٪ |
| **جمع** | **14** | **100٪** |

با توجه به شمارش‌های `[3, 2, 5, 1, 3]`، میانگین تعداد فایل در هر ژانر **2.80**، میانه **3**، واریانس جامعه (ddof=0) **1.76**، واریانس نمونه (ddof=1) **2.20** و انحراف معیار جامعه **1.33** است. در اینجا شمارش‌های هر پنج ژانر ثبت‌شده تحلیل شده‌اند؛ بنابراین واریانس جامعه، توصیف اصلی همین metadata است.

Hip-hop بیشترین نمونه و Jazz کمترین نمونه را دارد. این داده کوچک و نامتوازن است؛ یک نمونهٔ Jazz برای ارزیابی مدل کافی نیست و نتیجه‌ها را نمی‌توان به کل موسیقی‌ها تعمیم داد. لازم است پیش از آموزش/ارزیابی مدل، نمونه‌های بیشتری برای هر سبک جمع‌آوری شود.

آمار بالا دربارهٔ **تعداد فایل‌ها در هر سبک** است. metadata فقط نام فایل، مسیر و برچسب genre دارد؛ پس از این CSV نمی‌توان میانگین و واریانس ویژگی‌های خود سیگنال مثل MFCC را محاسبه کرد.

برای بازتولید از ریشهٔ پروژه:

```bash
python src/descriptive_stats.py --metadata data/processed/metadata.csv --output reports/plots
```

گزارش جزئیات در `reports/descriptive_statistics.md` و کد تحلیل در `src/descriptive_stats.py` است. اعداد باید با اجرای مجدد روی نسخهٔ فعلی CSV تأیید شوند.
